### RUN_002 Lessons Backlog (running — harvest into `RUN_002_LESSONS.md` at SP6)

**L1 — JSDOM env + jest-dom matchers don't auto-apply; kit pattern is per-file.** First DataTable test pass surfaced two friction points the kit "convention" hadn't surfaced upfront: `jest.config.js` defaults to `testEnvironment: 'node'` (Phase-1 component tests override per-file with `/** @jest-environment jsdom */` pragma); and `@testing-library/jest-dom` matchers must be `import`ed per file (`import '@testing-library/jest-dom';`). Both patterns visible by grep of any Phase-1 component test (`src/__tests__/admin/AddMemberForm.test.tsx`) but invisible from `jest.config.js` itself. **Expected:** component tests work with `render()` + `getByText()` out of the box. **Reality:** 8/8 failures with `document is not defined` until the pragma landed, then 6 with `toBeInTheDocument is not a function` until the import landed. **What we'd do differently:** for the first component test in any cluster, grep an existing kit component test for its head matter and copy the pragma + matchers import. Cheaper than diagnosing two failure modes. Also: kit's `jest.setup.ts` could add `import '@testing-library/jest-dom'` globally — would obviate the per-file import — but that's a v3 kit harvest task, not in scope for this run.

**L2 — JSDOM has both desktop and mobile DOM regardless of viewport; query by role, not text.** DataTable renders BOTH the desktop `<table>` AND the mobile card grid in JSDOM at the same time (Tailwind media queries don't run; both wrappers exist in DOM). Column labels like "Name" appear in 3 places: 1× desktop `<th>`, 2× mobile card grids (one per row). `screen.getByText("Name")` throws "found multiple elements." **What we'd do differently:** use `getByRole("columnheader", { name: /name/i })` for header-specific queries; use `getAllByText()` for cell-value queries; use `data-testid` for wrapper queries. The "verify both structures render" assertion via testid is the right shape — the visual viewport check is the C4 seam-walk's job.
