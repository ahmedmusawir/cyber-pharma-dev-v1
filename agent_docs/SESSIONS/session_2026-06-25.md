## Post-C5 regression (caught by operator) ✅ FIXED
The C4-fix navbar outside-tap dismiss broke the **mobile theme toggle**: the `ThemeToggler` Radix dropdown portals its items to `document.body` OUTSIDE the header, so an outside-`pointerdown` close fired on theme picks → menu collapsed mid-tap → fell through to a page nav. Fix: a **Radix-popper guard** (`closest('[data-radix-popper-content-wrapper]')` bails) + a `ThemeToggler` `onSelect` so a deliberate theme pick **closes** the menu cleanly. Operator then asked the menu to close on theme-pick (it was staying open) — that's what `onSelect={closeMenu}` delivers. `Navbar.mobile.test.tsx` → 7 tests (all close paths + guard + theme-close).
