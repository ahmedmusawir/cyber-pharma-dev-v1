# stark-kit-residue-cleaner

The post-clone cleanup ritual for apps built on the Stark starter kit.

Every factory app starts as a kit clone, learns from the kit's demo curriculum
(example portals, user CRUD, RBAC demos), builds its own surfaces, and then must
shed the scaffolding. This Agent Skill runs that shed: a read-only consumer trace
produces a DELETE/KEEP/COUPLED kill-list report, the operator rules on it, and the
approved cleanup executes under exact-count gates with a live-walk finale.

**Activate:** tell the agent — "go read <path>/stark-kit-residue-cleaner/CLAUDE.md and follow it."

Born from the MissionControl Phase 1 run (2026-07): 100 paths shed, 2 surgical
edits, tests 81→8 exactly as predicted, 15/15 live walk. v0.9 pending
retrospective delta + activation test → v1.0.
